# ✈️ Hệ thống Quản lý và Đặt Tour Du lịch (Tour Management System)

Dự án là một ứng dụng web thương mại điện tử cho phép người dùng tìm kiếm, đặt tour du lịch trực tuyến và cung cấp một hệ thống quản lý tổng thể cho quản trị viên/quản trị website. 

## 💻 Công nghệ & Thư viện sử dụng
* **Ngôn ngữ:** JavaScript
* **Backend:** Node.js, Express.js
* **Cơ sở dữ liệu:** MongoDB (Mongoose)
* **View Engine:** Pug
* **Lưu trữ đám mây:** Cloudinary (Lưu trữ hình ảnh)
* **Thư viện nổi bật:** Express-session & Flash (Quản lý phiên, thông báo), Multer (Upload file), JustValidate (Validate form), Bcrypt (Bảo mật mật khẩu), Moment.js.
